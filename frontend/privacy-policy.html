Privacy Policy

This page explains the information this EditMaster demo stores when you use the site.

Information you provide

If you create an account, the site stores your email, optional display name, and a password hash to support sign-in. It stores lesson completion, bookmarks, and quiz results with your account. If you subscribe, your email address is stored for the updates list.

How information is used

Account details support sign-in and personalized learning progress. Newsletter addresses are stored as subscriptions; the current demo does not send newsletter emails.

Storage and security

In this self-hosted version, application data is stored in a local JSON file in the backend data folder. Keep the server and that file secure. This demo does not include a hosted privacy or data deletion service.
